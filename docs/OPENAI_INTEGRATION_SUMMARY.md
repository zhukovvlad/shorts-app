# Добавлена поддержка генерации изображений через OpenAI DALL-E

## Что было сделано

### 1. Расширен интерфейс моделей изображений
- Добавлен тип `ImageProvider` с вариантами `'replicate' | 'openai'`
- Интерфейс `ImageModel` теперь поддерживает оба провайдера
- Добавлены опциональные поля `openaiModel` и сделано опциональным `replicateModel`

### 2. Добавлены новые модели OpenAI
В `lib/imageModels.ts` добавлены 3 новые модели:

#### DALL-E 3
- Передовая модель с отличным пониманием текста
- Размер: 1024x1792 (9:16)
- Качество: ultra, Скорость: medium
- Pro модель ✅

#### DALL-E 3 HD
- Максимальное качество детализации
- Размер: 1024x1792 (9:16)
- Качество: ultra, Скорость: slow
- Pro модель ✅

#### DALL-E 2
- Быстрая и экономичная модель
- Размер: 512x512 (квадрат)
- **Автоматическая конвертация в 9:16** с помощью Sharp
- Качество: standard, Скорость: fast

**Техническая деталь:** Квадратные изображения от DALL-E 2 автоматически обрабатываются функцией `convertTo9x16()`:
- Конвертация применяется только к квадратным изображениям (512x512)
- Изображения уже в 9:16 формате пропускаются (в пределах 5% погрешности)
- При ошибках конвертации возвращается оригинальное изображение
- Преобразование использует Sharp с `fit: 'cover'` для формата 1008x1792

### 3. Реализована обработка OpenAI
В `app/actions/image.ts`:
- Добавлена функция `processImageWithOpenAI()` для генерации через DALL-E
- **Ленивая инициализация OpenAI клиента** - создается только при использовании
- **Валидация API ключа** - четкая ошибка при отсутствии `OPENAI_API_KEY`
- **Автоматическая конвертация в 9:16** - функция `convertTo9x16()` с использованием Sharp
- Функция `processImage()` теперь маршрутизирует запросы в зависимости от провайдера
- Сохранена полная совместимость с существующими Replicate моделями

**Важно:** 
- `OPENAI_API_KEY` требуется только при использовании DALL-E моделей
- DALL-E 2 автоматически конвертируется из 512x512 в 1008x1792 (9:16)
- Replicate модели работают независимо

## Стоимость (приблизительная)

- **DALL-E 3 Standard**: ~$0.040 за изображение (1024x1792)
- **DALL-E 3 HD**: ~$0.080 за изображение (1024x1792)
- **DALL-E 2**: ~$0.020 за изображение (512x512)

Для сравнения, Replicate модели обычно стоят $0.001-0.010 за изображение.

## Проблемы и решения

### Проблема: DALL-E 2 генерирует квадратные изображения
**Решение**: Используйте DALL-E 3 для вертикального формата 9:16

### Проблема: Медленная генерация с DALL-E 3 HD
**Решение**: Используйте стандартный DALL-E 3 или переключитесь на FLUX модели если скорость критична

### Проблема: API quota exceeded
**Решение**: Проверьте лимиты в OpenAI dashboard и увеличьте квоту или используйте Replicate модели
