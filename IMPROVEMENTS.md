  ```typescript
  const goToPrevious = () => {
    if (selectedImage && selectedImage.index > 0) {
      setSelectedImage({
        url: imageLinks[selectedImage.index - 1],
        index: selectedImage.index - 1
      })
    }
  }

  const goToNext = () => {
    if (selectedImage && selectedImage.index < imageLinks.length - 1) {
      setSelectedImage({
        url: imageLinks[selectedImage.index + 1],
        index: selectedImage.index + 1
      })
    }
  }

  useEffect(() => {
    if (!selectedImage) return
    
    const handleKeyDown = (e: KeyboardEvent) => {
      e.preventDefault() // Prevent default browser behavior
      
      if (e.key === 'ArrowLeft') {
        goToPrevious()
      } else if (e.key === 'ArrowRight') {
        goToNext()
      }
    }
    
    window.addEventListener('keydown', handleKeyDown)
    return () => window.removeEventListener('keydown', handleKeyDown)
  }, [selectedImage, imageLinks])
  ```

**Критическое исправление retry gate:**
Исправлена off-by-one ошибка где на последней разрешенной попытке (attemptsMade === maxAttempts - 1) система неправильно определяла shouldRetry=true, несмотря на то что BullMQ уже не запланирует следующий retry. Это приводило к пропуску обновления БД, оставляя processing=true навечно и заставляя UI ждать бесконечно.

Было:
```typescript
const shouldRetry = attemptsMade < maxAttempts && isRetryableError(error);
retryCount: shouldRetry ? attemptsMade + 1 : undefined
```

Стало:
```typescript
const attemptNumber = attemptsMade + 1;
const shouldRetry = attemptNumber < maxAttempts && isRetryableError(error);
retryCount: shouldRetry ? attemptNumber : undefined
```

### Video Page UI Improvements (v1.6.8)

#### Общее описание
Комплексная переработка дизайна и лейаута страницы видео с фокусом на визуальную иерархию, читаемость и доступность. Реализован современный grid-based лейаут с sticky-видео, реорганизованной action-панелью и улучшенным представлением контента.

#### Ключевые изменения

**1. Новый Transcript компонент (`app/components/Transcript.tsx`)**
- Collapsible блок с автоматическим сворачиванием длинного контента
- Gradient fade эффект внизу свернутого состояния
- Кнопка "Show more/Show less" с плавными переходами
- **Accessibility:**
  - Уникальный `id` через React `useId()` для каждого экземпляра
  - Корректный `aria-controls` связывает кнопку с контентом
  - `aria-expanded` отражает текущее состояние
  - Автоматическое скрытие кнопки когда контент короткий
  - Измерение реальной высоты через `useRef` и `scrollHeight`
- Настраиваемая высота свернутого состояния (`collapsedMaxHeight`)
- Типографика оптимизирована для читаемости (line-height: 1.75)

**2. Реорганизация Action Bar (`app/components/videoActions.tsx`)**
- Гибкий компонент с поддержкой `layout="row"` и `layout="column"`
- Пропсы `showBackButton` и `onlyBackButton` для тонкой настройки
- В режиме row: кнопки равной ширины через `flex-1 min-w-0`
- Download (primary), Copy Link (secondary), Delete (destructive) в одну строку
- "Back to Dashboard" изолирована для размещения справа
- Адаптивное поведение на мобильных устройствах

**3. Grid-лейаут страницы видео (`app/videos/[videoId]/page.tsx`)**
- Двухколоночная сетка: 460px (видео) + 1fr (контент)
- Верхняя панель над сеткой:
  - Слева: action-кнопки выровнены по ширине видео
  - Справа: "Back to Dashboard" прижата к правому краю
  - Flex `justify-between` для распределения пространства
- Sticky-позиционирование видео (`lg:sticky lg:top-16`)
- Карточка видео с тенью и border для визуального отделения
- Metadata badges (длительность, количество изображений, дата)
- Адаптивные gap'ы: `gap-y-3 gap-x-6` на мобиле, `gap-y-4 gap-x-8` на desktop

**4. Error Resilience (`app/lib/findPrompt.ts`)**
- Изменено поведение при ошибках БД: return `null` вместо throw
- Страница не падает с 500 при недоступности базы
- Условный рендеринг prompt input и transcript
- Graceful empty states с понятными сообщениями пользователю

**5. Spacing Optimization**
- Уменьшен top padding контейнера (`pt-3` вместо `pt-6`)
- Убран лишний bottom margin у action bar
- Prompt input выровнен с остальными секциями (`max-w-3xl`)
- Оптимизированные вертикальные отступы для плотного view

#### Преимущества
- **UX:** Улучшенная визуальная иерархия и navigation flow
- **Accessibility:** WCAG-compliant компоненты с корректной ARIA-разметкой
- **Performance:** Условный рендеринг уменьшает DOM overhead
